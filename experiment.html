Inertia · 래틀백 탐구 · 실험 방법

래틀백 실험,
처음부터 끝까지

촬영 장치 만들기부터 Tracker 분석, 엑셀 그래프까지 한 단계도 빼지 않고 적었다. 이 순서대로 하면 막대 각도를 바꿔 가며 회전 역전 시간을 재고, 1/tr–θ 그래프 한 장을 얻는다.

시작

한눈에 보기

이 문서대로 하면 막대 각도 δ를 바꿔 가며 래틀백의 회전 역전 시간 tr을 재고, 마지막에 "1/tr–θ 그래프" 한 장을 얻습니다. 기준 장치는 작은 래틀백(180 × 60 × 20 mm, 채움 100%)에 양쪽 동전 1개씩입니다.

전체 순서는 다섯 단계입니다.

  1. 준비: 래틀백 무게를 재고, 스티커를 붙이고, 막대 각도를 맞춘다.
  2. 촬영: 유리판 위에서 래틀백을 돌리고, 위에서 240 fps로 찍는다.
  3. Tracker 추적: 영상에서 스티커 두 개를 따라가게 해서 회전 각속도 ω를 얻는다.
  4. 값 읽기: ω 그래프에서 처음 회전 속력 ω₀와 역전 시간 tr을 읽는다.
  5. 엑셀 분석: δ로 어긋남 각 θ를 계산하고, 1/tr–θ 그래프를 그려 직선인지 본다.

용어 세 개만 먼저 기억하세요.

기호 이름 뜻
δ 막대 각도 무게추 막대가 바닥의 긴 축과 이루는 각. 우리가 직접 바꾸는 값
θ 어긋남 각 δ 때문에 생기는 실제 비틀림. δ로 계산하는 값
tr 회전 역전 시간 손을 놓은 순간부터 회전이 멈추는 순간(ω = 0)까지 걸린 시간

1단계

준비물

모두 학교나 집에 있는 물건이고, 새로 살 것은 동그란 스티커 정도입니다.

2단계

래틀백 준비

실험 전에 무게 세 가지를 재고, 스티커 두 개를 붙이고, 막대 각도를 맞춘 뒤 사진으로 확인합니다.

2-1. 무게 재기

  1. 저울을 평평한 곳에 놓고 영점(0)을 맞춥니다.
  2. 바닥만 올려 무게를 재고 → M으로 적습니다. 너트를 이미 넣었다면 너트까지 포함해서 잽니다.
  3. 팔(볼트·와셔 포함)을 재고 → m팔로 적습니다.
  4. 동전 1개를 재고 → m으로 적습니다. (500원은 보통 7.7 g)

이 세 값은 8번에서 θ를 계산할 때 씁니다.

2-2. 스티커 붙이기

Tracker는 화면에서 "모양이 똑같은 작은 조각"을 프레임마다 찾아가는 프로그램입니다. 래틀백은 빙빙 돌기 때문에, 돌아도 모양이 변하지 않는 동그란 스티커를 써야 자동 추적이 잘 됩니다. 글자나 네모가 있는 스티커는 돌면 모양이 바뀌어서 추적이 끊깁니다.

  1. 점 C (가운데): 볼트 머리 위에 흰색 동그란 스티커를 붙입니다.
  2. 점 A (끝): 한쪽 동전 받침 위(동전 위)에 색이 다른 동그란 스티커를 붙입니다.
  3. 스티커 주변 1 cm는 다른 무늬나 글자가 없게 합니다. 눈금이나 글자가 가까이 있으면 Tracker가 헷갈립니다.

스티커 무게(0.1 g 안팎)는 너무 작아서 결과에 영향을 주지 않습니다.

2-3. 막대 각도 δ 맞추기

  1. 볼트를 반 바퀴 풀어 팔이 돌아가게 합니다.
  2. 팔 가운데 창으로 보이는 바닥의 눈금을 원하는 각도에 맞춥니다. 긴 눈금이 10° 단위, 짧은 눈금이 5° 단위입니다.
  3. 팔이 돌아가지 않게 한 손으로 잡고, 다른 손으로 볼트를 꽉 조입니다.
  4. 사진으로 확인하기: 눈금은 눈으로 맞춘 것이라 1~2° 틀릴 수 있습니다. 그래서 실제 각도를 재서 그 값을 씁니다.
    1. 3번의 휴대폰 거치대에서 래틀백을 위에서 사진 한 장 찍습니다.
    2. Tracker에서 그 사진을 열고, 위쪽 메뉴 Track → New → Measuring Tools → Protractor(각도기)를 고릅니다.
    3. 각도기의 꼭짓점을 볼트 중심에, 한 팔을 바닥의 긴 축 끝에, 다른 팔을 막대 가운데 선 끝에 맞춥니다.
    4. 표시되는 각도를 δ(실제)로 기록합니다.
  5. 조건 하나를 끝낼 때마다 사진을 다시 찍어, 실험 중 팔이 돌아가지 않았는지 확인합니다.

3단계

바닥과 카메라 설치

유리판과 휴대폰이 둘 다 수평이어야 합니다. 클램프와 집게 대신, 책 더미 두 개 위에 판을 걸치고 휴대폰을 엎어 놓는 방법을 씁니다. 판이 수평이면 그 위에 놓인 휴대폰도 자동으로 수평이 되어, 카메라가 정확히 아래를 향합니다.

3-1. 바닥(유리판)

  1. 흔들리지 않는 책상이나 실험대를 고릅니다.
  2. 검은 종이를 깔고 그 위에 유리판을 올립니다. 유리 모서리는 테이프로 감싸 다치지 않게 합니다.
  3. 휴대폰 수평계 앱을 켜고 유리판 가운데에 놓습니다. 가로, 세로 두 방향 모두 0.0°가 되게 합니다.
  4. 기울어 있으면 낮은 쪽 유리판 밑에 종이를 접어 끼웁니다. 0.2° 이하면 통과입니다.
  5. 극세사 천으로 유리판을 닦습니다. 실험 중에도 10번에 한 번씩 닦습니다.

3-2. 휴대폰 거치대

  1. 두꺼운 판(아크릴판이나 폼보드) 가운데에 휴대폰 뒷면 카메라가 들어갈 만한 구멍(약 3 × 3 cm)을 뚫습니다. 폼보드는 커터로 자르면 됩니다.
  2. 유리판 양옆에 높이가 같은 책 더미를 하나씩 쌓습니다. 높이는 유리판에서 약 40~50 cm입니다.
  3. 두 책 더미 위에 판을 걸치고, 구멍이 래틀백을 돌릴 자리 바로 위에 오게 합니다.
  4. 판 위에 수평계 앱을 올려 0.0°가 되게 책 더미 높이를 종이로 조절합니다.
  5. 휴대폰을 화면이 위를 보게 엎어 놓고, 카메라가 구멍으로 아래를 보게 합니다. 휴대폰이 밀리지 않게 테이프로 붙입니다.
  6. 수직 확인: 유리판 가운데에 동전 하나를 놓고 화면을 봅니다. 동전이 타원형이 아니라 동그라미로 보이면 카메라가 수직입니다.
  7. 화면에 래틀백이 가로의 절반 정도 크기로 보이면 됩니다. 돌면서 조금씩 움직이니 가장자리에 여유를 둡니다.

3-3. 조명

  • 형광등 바로 아래에서 찍으면 유리에 빛이 반사되어 하얀 얼룩이 생깁니다. 화면에 반사가 보이면 조명을 비스듬하게 두거나 스탠드를 옆에서 비춥니다.
  • 밝을수록 스티커가 번지지 않게(흐리지 않게) 찍힙니다. 슬로모션은 빛을 많이 쓰므로 너무 어두운 곳은 피합니다.

4단계

촬영하기

실험 전에 시간 검사를 한 번 하고, 조건마다 같은 순서로 촬영합니다.

4-1. 시간 검사 (처음 한 번만)

슬로모션 영상은 휴대폰이 저장하거나 보낼 때 모양을 바꾸는 경우가 있어서, 초가 정말 맞는지 먼저 확인해야 합니다.

  1. 다른 휴대폰에서 스톱워치를 켜고, 유리판 위에 놓습니다.
  2. 거치대 휴대폰으로 슬로모션(240 fps)을 켜고 스톱워치를 5초 동안 찍습니다.
  3. 이 영상을 노트북으로 옮기고, 5-2번처럼 Tracker에서 열고 Frame rate를 240으로 맞춥니다.
  4. Tracker의 시간으로 1초가 지날 때 스톱워치도 1초가 지났는지 확인합니다. 맞으면 통과입니다.
  5. 틀리면 영상을 옮기는 방법이 문제입니다.
    • 아이폰: 사진 앱에서 슬로모션 영상을 편집해, 아래 느린 구간 막대를 처음부터 끝까지 늘립니다. 앞뒤 일부가 보통 속도로 남아 있으면 시간이 어긋납니다. 에어드롭으로 보낼 때는 "옵션 → 모든 사진 데이터"를 켭니다.
    • 갤럭시: "슈퍼 슬로우"(960 fps)가 아니라 "슬로우 모션"(240 fps)으로 찍습니다. 카톡으로 보내면 압축되니, USB 케이블이나 구글 드라이브로 원본을 옮깁니다.

4-2. 실험 조건

시간이 부족하면 최소판부터 하고, 여유가 있을 때 나머지를 채웁니다.

막대 각도 δ 0° 5° 10° 15° 20° 30° −20°
동전 1개씩일 때 예상 θ 0° 1.9° 3.7° 5.6° 7.4° 10.9° −7.4°
최소판 (각 5회) ○ ○ ○ ○ ○
전체판 (각 10회) ○ ○ ○ ○ ○ ○ ○
역할 대조군: 역전이 없어야 함 측정 측정 측정 측정 측정 거울상: 방향만 반대여야 함

예상 θ는 바닥 140 g, 팔 16 g으로 계산한 값입니다. 실제 θ는 8번에서 잰 무게로 다시 계산합니다.

4-3. 불안정 방향 찾기

래틀백은 한쪽으로 돌리면 멈췄다가 반대로 돌고(불안정 방향), 다른 쪽으로 돌리면 그냥 계속 돕니다(안정 방향). 실험은 항상 불안정 방향으로 돌립니다.

  1. δ를 맞춘 뒤 시계 방향, 반시계 방향으로 한 번씩 돌려 봅니다.
  2. 멈췄다 반대로 도는 쪽을 기록합니다. δ가 +일 때와 −일 때 불안정 방향이 반대이니, 조건이 바뀔 때마다 다시 확인합니다.
  3. δ = 0°에서는 양쪽 모두 5회씩 찍습니다. 어느 쪽도 역전하지 않아야 정상입니다.

4-4. 한 번 측정하는 순서

  1. 래틀백을 유리판 가운데(카메라 바로 아래)에 놓고, 흔들림이 완전히 멈출 때까지 기다립니다.
  2. 슬로모션 녹화를 시작합니다.
  3. 볼트 머리를 엄지와 검지로 가볍게 잡고, 불안정 방향으로 한 번 비틀어 돌린 뒤 놓습니다. 매번 같은 세기, 같은 동작으로 합니다. 위에서 누르지 않게 조심합니다.
  4. 래틀백이 멈췄다가 반대로 1초 정도 더 돈 뒤 녹화를 끕니다.
  5. 바로 기록지에 파일 번호, δ, 회차, 눈으로 본 특이사항을 적습니다.
  6. 나중에 파일 이름을 d20_03처럼(δ 20°, 3회차) 바꿉니다. δ = −20°는 dm20_03처럼 씁니다.

처음 회전 속력을 비슷하게 맞추는 것이 가장 중요합니다. 너무 세게 돌리면 흔들림이 커져 역전이 불규칙해집니다. 본 실험 전에 한 사람이 10번쯤 연습하고, 돌리는 사람은 끝까지 한 명으로 정합니다.

4-5. 다시 찍어야 하는 경우 (제외 기준)

아래에 해당하면 그 회차는 버리고 다시 찍습니다. 실험 전에 정해 두어야 나중에 "마음에 안 드는 값만 빼기"가 되지 않습니다.

  • 돌리면서 래틀백을 위에서 눌렀거나 손에 다시 닿았다.
  • 래틀백이 미끄러지며 옆으로 3 cm 넘게 움직였다.
  • 유리판 가장자리나 다른 물건에 닿았다.
  • 화면 밖으로 나갔다.
  • 처음 회전 속력 ω₀가 정한 범위를 벗어났다. (7번에서 확인)

5단계

Tracker 준비

Tracker는 무료 영상 분석 프로그램입니다. 영상을 열면 가장 먼저 프레임 속도를 240으로 바꿔야 합니다. 이걸 빼먹으면 모든 시간이 8배로 틀어집니다.

5-1. 설치

  1. physlets.org/tracker에 들어갑니다.
  2. Download에서 내 컴퓨터 운영체제(Windows 또는 Mac)에 맞는 설치 파일을 받습니다.
  3. 설치 파일을 실행하고 계속 "다음"을 누릅니다. Java는 따로 깔 필요 없습니다.
  4. Mac에서 "확인되지 않은 개발자"라고 뜨면, 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누릅니다.

5-2. 영상 열고 설정하기

  1. Tracker를 켜고, 영상 파일을 Tracker 창 안으로 끌어다 놓습니다. (또는 File → Open File)
  2. 영상이 안 열리거나 검은 화면만 나오면, 휴대폰에서 mp4로 다시 내보내거나 영상 변환 프로그램(예: HandBrake)으로 mp4로 바꾼 뒤 다시 엽니다.
  3. 화면 아래 재생 막대에 있는 필름 모양 아이콘(Clip Settings)을 누릅니다. 창이 하나 뜹니다.
  4. Frame rate 칸을 240으로 고칩니다. 슬로모션 영상은 보통 30으로 읽힙니다.
  5. Start frame 찾기: 창을 둔 채로 재생 막대를 한 칸씩 움직여, 손가락이 볼트에서 떨어지는 첫 프레임을 찾습니다. 그 번호를 Start frame에 넣습니다. 이제 그 순간이 t = 0입니다.
  6. End frame: 래틀백이 반대로 돈 뒤 조금 지난 프레임을 넣습니다. 끝부분을 잘라야 분석이 빨라집니다.
  7. Step size는 1로 둡니다. (프레임을 건너뛰지 않기)
  8. OK를 누릅니다.

한 조건의 첫 영상을 다 분석했으면 File → Save Tab As로 .trk 파일을 저장합니다. 다음 영상은 그 .trk를 열고 File → Import → Video로 영상만 바꾸면, 설정을 다시 하지 않아도 됩니다. (Start frame은 영상마다 다시 맞춥니다.)

6단계

Tracker로 점 따라가기

점 C(가운데)와 점 A(끝)를 프레임마다 찍어 두면, Tracker가 A가 C를 중심으로 몇 도 돌았는지 계산해 줍니다. 손으로 하나씩 찍을 수도 있지만 영상 하나에 수백 프레임이라, 자동 추적(Autotracker)을 씁니다.

6-1. 점 C 만들고 자동 추적하기

  1. 재생 막대를 맨 앞(Start frame)으로 돌립니다.
  2. 위쪽 메뉴 Track → New → Point Mass를 누릅니다. "mass A"라는 점이 생깁니다.
  3. 새 점 이름을 더블클릭(또는 오른쪽 클릭 → Name)해서 C로 바꿉니다.
  4. 점 C를 고른 채로, 위쪽 도구 막대의 과녁 모양 아이콘(Autotracker)을 누릅니다. 자동 추적 창이 뜹니다.
  5. 키보드의 Ctrl + Shift(Mac은 Command + Shift)를 누른 채로, 화면에서 흰 스티커 정가운데를 클릭합니다. 동그라미와 사각형 두 개가 나타납니다.
    • 안쪽 동그라미(템플릿): Tracker가 찾을 모양입니다. 가장자리를 끌어 스티커보다 조금만 크게 맞춥니다.
    • 바깥 점선 사각형(검색 범위): 다음 프레임에서 찾아볼 구역입니다. 점 C는 거의 안 움직이니 기본 크기로 둡니다.
  6. 자동 추적 창에서 Search 버튼을 누릅니다. Tracker가 프레임마다 스티커를 찾아 점을 찍습니다.
  7. 끝날 때까지 기다린 뒤, 재생 막대를 움직여 점이 스티커 위에 계속 있는지 눈으로 확인합니다.

6-2. 점 A 만들고 자동 추적하기

  1. 다시 Start frame으로 돌아갑니다.
  2. Track → New → Point Mass로 점을 하나 더 만들고 이름을 A로 바꿉니다.
  3. 6-1의 4~5번처럼 Ctrl + Shift + 클릭으로 끝 스티커를 지정합니다.
  4. 검색 범위(바깥 점선 사각형)를 넓힙니다. 점 A는 빠르게 돌기 때문에 한 프레임 사이에도 꽤 움직입니다. 스티커 크기의 3~4배 정도로 당기세요.
  5. Search를 누르고, 6-1의 7번처럼 결과를 확인합니다.

6-3. 기준점을 C로 바꾸기

래틀백은 돌면서 조금씩 미끄러져 자리가 바뀝니다. 기준점을 C로 바꾸면 이 움직임을 빼고 "가운데를 중심으로 한 회전"만 남습니다.

  1. 위쪽 메뉴 Coords → Reference Frame → C를 고릅니다.
  2. 화면이 C를 가운데에 고정한 모습으로 바뀌면 성공입니다.

6-4. 자동 추적이 안 될 때

증상 원인 해결
몇 프레임 가다가 멈추고 노란 표시가 뜨며 더 안 찾음 점이 너무 빠르게 움직여 검색 범위를 벗어남 검색 범위(바깥 사각형)를 더 크게 하고 그 프레임부터 Search 다시
엉뚱한 곳(눈금, 글자, 반사)에 점이 찍힘 비슷한 모양이 근처에 있음 그 프레임에서 Ctrl + Shift + 클릭으로 다시 지정하고 Search. 스티커 주변을 깔끔하게
점이 조금씩 밀려나감 회전하며 스티커 모양이 변함 동그란 스티커로 바꾸기. 자동 추적 창의 Evolution rate를 올리면 템플릿이 조금씩 따라 변함
처음부터 대부분 못 찾음 영상이 흐리거나 어두움 더 밝은 조명에서 다시 촬영. 자동 추적 창의 Automark 기준을 조금 낮춤
몇 프레임만 틀림 그 프레임만 흐릿함 그 프레임에서 점을 마우스로 끌어 스티커 위에 직접 옮기기

어떻게 해도 자동 추적이 안 되면 손으로 찍어도 됩니다. 점을 고른 뒤 Shift + 클릭으로 스티커를 찍으면 다음 프레임으로 자동으로 넘어갑니다. 이때는 Clip Settings의 Step size를 4로 해서 4프레임마다(1/60초마다) 찍으면 일이 훨씬 줄어듭니다.

7단계

ω₀와 tr 읽기

Tracker에서 점 A의 각속도 ω 표를 엑셀로 옮긴 뒤, ω가 처음 0이 되는 시각을 계산합니다. 그 시각이 tr입니다.

7-1. Tracker에서 ω 표 띄우고 복사하기

  1. 오른쪽 위 그래프 구역에서 보고 있는 점이 A인지 확인합니다. 아니면 그래프 위쪽 선택 칸에서 A를 고릅니다.
  2. 그래프의 세로축 이름을 클릭하고 ω(각속도)를 고릅니다. 가로축은 t(시간)입니다.
  3. 그래프 모양을 확인합니다. 처음에는 ω가 한쪽(예: +)에 있다가 점점 0에 가까워지고, 0을 지나 반대쪽(−)으로 갑니다. 이 0을 지나는 순간이 역전입니다.
  4. 그래프 아래 표(Table)에서 열 선택 버튼을 눌러 t와 ω만 보이게 합니다. 단위는 표 제목 줄에 표시됩니다(각도 단위는 Edit → Preferences에서 도·라디안 중 고를 수 있고, 모든 영상에서 같게 둡니다).
  5. 표 안에서 오른쪽 클릭 → Copy Data(또는 Select All 후 복사)를 누릅니다.
  6. 엑셀을 열고 새 시트 이름을 영상 이름(예: d20_03)으로 바꾼 뒤, A1 칸에 붙여넣습니다. A열은 t, B열은 ω가 됩니다.

7-2. ω 정리하기 (엑셀)

점 A는 앞뒤로 흔들리면서 돌기 때문에 ω가 지글지글 흔들립니다. 그대로 쓰면 역전 근처에서 0을 여러 번 지나가 버려서, 먼저 매끄럽게 만듭니다.

  1. 튀는 값 지우기: θ가 +180°에서 −180°로 넘어가는 순간, ω가 한두 칸만 엄청 크게 튀어오릅니다. 앞뒤 값보다 3배 넘게 큰 값은 지워서 빈칸으로 둡니다.
  2. 부호 맞추기: 처음 ω가 음수로 시작하면, C열에 =-B2를 넣고 아래로 채워 부호를 뒤집습니다. (모든 영상에서 "처음은 +"로 맞추기 위해서입니다.) 양수로 시작하면 =B2를 넣습니다.
  3. 이동 평균: D6 칸에 =AVERAGE(C2:C10)을 넣고 아래로 끌어 채웁니다. 앞뒤 9프레임(약 0.04초)을 평균 낸 값이라 지글지글한 흔들림이 줄어듭니다. 이 D열을 ω(매끄러운)라고 부릅니다.
  4. 그래프로 확인: A열과 D열을 골라 삽입 → 분산형 차트를 그려 봅니다. 하강해서 0을 한 번 깔끔하게 지나면 잘 된 것입니다.

7-3. ω₀ 구하기

ω₀는 손을 놓은 직후 0.1초(24프레임) 동안의 평균 회전 속력입니다.

  • 빈 칸에 =AVERAGE(C2:C25)를 넣습니다. (손으로 찍어서 Step size가 4였다면 C2:C7)
  • 범위 정하기: 처음 5회의 ω₀ 평균을 구하고, 그 값의 ±15%를 허용 범위로 정합니다. 예를 들어 평균이 8.0 rad/s면 6.8~9.2 rad/s입니다. 이 범위를 벗어난 회차는 다시 찍습니다. 정한 범위는 모든 조건에 똑같이 씁니다.

7-4. tr 구하기

  1. D열(매끄러운 ω)을 위에서부터 내려가며, 처음으로 양수 → 0 또는 음수로 바뀌는 두 줄을 찾습니다.
  2. 윗줄의 시간·ω를 t₁, ω₁, 아랫줄의 시간·ω를 t₂, ω₂라고 합니다.
  3. 두 점을 직선으로 잇고 ω = 0이 되는 시각을 구합니다. 엑셀 식: =t₁ + ω₁*(t₂-t₁)/(ω₁-ω₂)
  4. 예시: t₁ = 2.4500 s, ω₁ = 0.06, t₂ = 2.4542 s, ω₂ = −0.03이면
    • tr = 2.4500 + 0.06 × 0.0042 / 0.09 = 2.4528 s
  5. 값을 아래 기록표에 적습니다. 눈으로 본 영상에서 멈추는 듯한 순간과 대충 맞는지도 확인합니다.

7-5. 기록표

영상 한 개가 한 줄입니다. 엑셀에 같은 열로 "전체기록" 시트를 만들어 모읍니다.

8단계

엑셀로 θ 계산하고 그래프 그리기

조건별로 1/tr의 평균을 내고, δ로 θ를 계산해 "가로축 θ, 세로축 1/tr" 그래프를 그립니다. 점들이 원점을 지나는 직선 근처에 놓이면 선행 연구의 예측(tr ∝ 1/θ)과 같은 결과입니다.

8-1. 조건별 평균 내기

  1. "전체기록" 시트에 열을 하나 더 만들고, 유효한 회차마다 =1/t_r을 계산합니다. (예: tr이 F열이면 =1/F2)
  2. "요약" 시트를 만들고 조건마다 한 줄씩 적습니다.
    • δ 실제: 그 조건에서 사진으로 잰 각도
    • 1/tr 평균: =AVERAGE(범위)
    • 1/tr 표준편차: =STDEV.S(범위) (값이 얼마나 흩어져 있는지)
    • tr 평균: 보고서 표에 쓸 값
  3. δ = 0°는 역전이 없으므로 tr이 무한대, 즉 1/tr = 0으로 적습니다. (그래프의 원점이 됩니다.)

8-2. θ 계산하기

θ는 다음 식으로 구합니다.

tan⁡2θ=Ksin⁡2δD0+Kcos⁡2δ,K=2ma2+D팔,D0=M(L2−W2)20\tan 2\theta = \frac{K\sin 2\delta}{D_0+K\cos 2\delta},\; K=2ma^2+D_{팔},\; D_0=\frac{M(L^2-W^2)}{20}

엑셀에서는 다음처럼 칸을 만들면 자동으로 계산됩니다.

  1. "요약" 시트 위쪽에 상수를 적습니다.
    • H1: M (바닥 무게, g) → I1에 2-1에서 잰 값
    • H2: m (동전 1개, g) → I2에 잰 값
    • H3: a (중심에서 동전까지, mm) → I3에 70
    • H4: D팔 (팔 자체의 값, g·mm²) → I4에 45700 (설계 치수로 계산한 값)
    • H5: D0 → I5에 =I1*(180^2-60^2)/20
    • H6: K → I6에 =2*I2*I3^2+I4
  2. δ 실제가 A열에 있다면, θ(°)를 넣을 칸에 아래 식을 붙여넣고 아래로 채웁니다.
    • =DEGREES(ATAN2($I$5+$I$6*COS(RADIANS(2*A2)), $I$6*SIN(RADIANS(2*A2))))/2
    • 엑셀의 ATAN2는 (가로, 세로) 순서라서 분모가 앞에 옵니다.
  3. 검산: M = 140, m = 7.7을 넣고 δ = 20이면 θ ≈ 7.4°가 나와야 합니다. 다르게 나오면 식을 다시 확인합니다.

8-3. 1/tr–θ 그래프 그리기

  1. "요약" 시트에서 θ 열과 1/tr 평균 열을 함께 선택합니다. (δ = −20° 줄은 빼고, δ = 0° 줄은 넣습니다.)
  2. 삽입 → 차트 → 분산형(점만 찍힌 것)을 고릅니다. 꺾은선형은 가로축 간격이 틀어지므로 쓰지 않습니다.
  3. 축 제목을 넣습니다: 가로 어긋남 각 θ (°), 세로 1/tr (1/s).
  4. 오차 막대: 차트를 클릭 → 오른쪽 위 + 버튼 → 오차 막대 → 기타 옵션 → 세로 오차 막대의 "사용자 지정"에서 양수·음수 값 모두 표준편차 열을 고릅니다.
  5. 추세선: + 버튼 → 추세선 → 기타 옵션에서 "선형"을 고르고, "수식을 차트에 표시"와 "R-제곱 값을 차트에 표시"를 체크합니다.
  6. 비례 확인: 같은 창에서 "절편 = 0"을 체크한 추세선도 하나 더 그려 봅니다. 원점을 지나는 직선이 잘 맞으면 "1/tr이 θ에 비례한다", 즉 "tr이 θ에 반비례한다"고 말할 수 있습니다.

8-4. δ = −20° 비교

−20°는 그래프에 넣지 않고 따로 비교합니다.

  • 역전 방향이 +20°와 반대인지 확인합니다.
  • tr 평균이 +20°와 표준편차 안에서 같은지 확인합니다. 같으면 바닥이 대칭으로 잘 만들어졌다는 증거입니다.

9단계

결과 해석과 자주 생기는 문제

그래프가 예측과 달라도 실패가 아닙니다. "어디서, 왜 달랐는지"를 설명하면 그것이 고찰입니다.

9-1. 그래프를 읽는 법

그래프 모양 뜻 보고서에 쓸 내용
점들이 원점을 지나는 직선 근처, R²가 0.9 이상 선행 연구 예측(tr ∝ 1/θ)과 같음 실제 물체에서도 반비례 관계가 성립함
θ가 작은 쪽은 직선, 큰 쪽은 아래로 휘어짐 선행 연구의 식은 θ가 작을 때만 맞음 어느 θ부터 벗어나는지가 이 실험의 발견
직선이지만 원점을 지나지 않음 δ = 0°에서도 작은 비틀림이 있거나, 마찰 때문에 역전이 늦어짐 바닥 모양의 오차 또는 에너지 손실의 영향
점이 제멋대로, 오차 막대가 큼 돌리는 세기나 조건이 매번 달랐음 ω₀ 범위, 유리판 청소, 수평을 다시 확인하고 재측정

9-2. 오차의 원인 (고찰에 쓸 내용)

  • 처음 회전 속력: 손으로 돌려서 매번 조금씩 다릅니다. ω₀ 범위를 정해 줄였지만 완전히 같지는 않습니다.
  • 에너지 손실: 선행 연구는 마찰과 공기 저항으로 잃는 에너지가 없다고 보았지만, 실제로는 있습니다.
  • 막대 각도: 눈금과 사진으로 맞춰 1° 안팎의 오차가 있습니다.
  • D₀와 D팔: 설계 치수로 계산한 값이라 실제 출력물과 조금 다를 수 있습니다.
  • 바닥 모양: 3D 출력의 층 자국과 사포질 때문에 완전한 타원체가 아닙니다.
  • 측정 방법: ω를 9프레임 평균으로 다듬었기 때문에 tr에 약 ±0.02초의 불확실성이 있습니다.

9-3. 실험 날 체크리스트

  • ☐ 무게 3개(M, m팔, m) 기록
  • ☐ 스티커 C, A 붙임 (동그란 것)
  • ☐ 유리판 수평 0.2° 이하, 거치대 수평, 동전이 동그랗게 보임
  • ☐ 시간 검사 통과 (스톱워치 1초 = Tracker 1초)
  • ☐ 돌리는 사람 1명 정하고 10회 연습
  • ☐ 조건마다 δ 사진 촬영, 불안정 방향 확인
  • ☐ 촬영 즉시 기록표 작성, 파일 이름 변경
  • ☐ 영상 원본을 공유 폴더에 백업
